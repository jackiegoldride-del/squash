# 🏆 Tournament & League Scheduler — MCP Server

שרת MCP לניהול תחרויות סקווש במועדון: טורנירי **נוק-אאוט** (8/16/32/64 שחקנים)
וליגות בשיטת **round robin** — כמה ליגות שרוצים בכל עונה, בכל גודל.

## התקנה

```bash
cd mcp-server
npm install
```

קובץ `.mcp.json` בשורש הריפו כבר רושם את השרת, כך ש-Claude Code טוען אותו
אוטומטית כשפותחים את הפרויקט. לחיבור מ-Claude Desktop מוסיפים ל-config:

```json
{
  "mcpServers": {
    "tournament-scheduler": {
      "command": "node",
      "args": ["/נתיב/מלא/אל/squash/mcp-server/index.js"]
    }
  }
}
```

כל הנתונים נשמרים בקובץ `mcp-server/data/competitions.json` (אפשר לשנות מיקום
עם משתנה הסביבה `TOURNAMENT_DATA_DIR`), כך שהתחרויות שורדות בין שיחות.

## הכלים

### נוק-אאוט
| כלי | מה עושה |
|---|---|
| `create_knockout` | יוצר מסלול הדחה ישירה ל-2–64 שחקנים. גודל המסלול (8/16/32/64) נקבע אוטומטית; אם המספר לא מדויק, המדורגים הגבוהים מקבלים Bye. סדר הרשימה = דירוג, או הגרלה אקראית עם `seeded: false` |
| `report_knockout_result` | רושם מנצח ומקדם אותו לשלב הבא, עד הכרזת אלוף/ה |
| `get_bracket` | מציג את המסלול המלא עם כל התוצאות |

### ליגות
| כלי | מה עושה |
|---|---|
| `create_league` | ליגת round robin אחת — כל אחד נגד כולם, 3–24 שחקנים (טיפוסי: 7–12). מספר אי-זוגי מקבל Bye בכל סיבוב. אופציה להלוך-חזור (`double_round`) |
| `create_season` | עונה שלמה במכה אחת: 1–10 ליגות לפי רמות, כל אחת עם השחקנים שלה |
| `record_league_result` | רישום תוצאה במשחקונים (3:0 / 3:1 / 3:2) |
| `get_standings` | טבלת הליגה: נצחונות, יחס משחקונים, נקודות |
| `get_fixtures` | לוח המשחקים לפי סיבובים, עם סינון לפי סיבוב או שחקן |

### כללי
| כלי | מה עושה |
|---|---|
| `list_competitions` | כל הטורנירים והליגות השמורים, עם סינון לפי עונה |
| `delete_competition` | מחיקת תחרות |

## ניקוד ושובר שוויון

ברירת מחדל: ניצחון = 3 נקודות, הפסד (ששוחק) = 1 נקודה. ניתן לשינוי בכל ליגה
עם `points_win` ו-`points_loss`. סדר הטבלה: נקודות ← הפרש משחקונים ← משחקונים
לזכות.
