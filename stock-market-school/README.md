# 🏫 בית הספר הקטן לשוק ההון

חבילת לימוד משפחתית מלאה — להורה ולילד בן 8 — ללימוד שוק ההון מאפס, כולל תוכנית השקעה מעשית.

## מה יש כאן

| קובץ | מה זה | איך משתמשים |
|---|---|---|
| [`curriculum.md`](curriculum.md) | תוכנית לימודים של 8 שבועות: סיפור + משחק + שאלה לכל מפגש | קוראים לפני כל מפגש שבועי |
| [`investing-guide.md`](investing-guide.md) | תוכנית ההשקעה בפועל: הוראת קבע חודשית לטווח ארוך + ניסוי 1,000 ₪ בסיכון גבוה | מדריך להורה |
| [`presentation.html`](presentation.html) | מצגת אינטראקטיבית (13 שקפים, גרף ריבית דריבית חי) | פותחים בדפדפן; חיצים/רווח לדפדוף |
| [`video.html`](video.html) | שיעור וידאו מונפש (~4 דקות) עם כתוביות וקריינות קולית | פותחים בדפדפן ולוחצים נגן |
| [`podcast.md`](podcast.md) | תסריטי פודקאסט מלאים (2 פרקים) + מתווה ל-4 נוספים | להקלטה משפחתית או להקראה |
| [`podcast.html`](podcast.html) | נגן שמקריא את הפודקאסט בקול, עם שני קולות | פותחים בדפדפן |

## סדר מומלץ

1. ההורה קורא את `investing-guide.md` ופותח הוראת קבע.
2. מתחילים את 8 השבועות של `curriculum.md` — המצגת והווידאו משמשים כעזרי הוראה במפגשים.
3. הפודקאסט לנסיעות ברכב / לפני שינה.
4. אחרי שבוע 8 — פותחים את ניסוי ה-1,000 ₪ יחד.

> ⚠️ כל החומר לימודי בלבד ואינו מהווה ייעוץ השקעות אישי המותאם לצרכיכם.
